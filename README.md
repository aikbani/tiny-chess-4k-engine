A compact chess engine in 4 KB of Python: 0x88 board, negamax with alpha-beta and principal-variation search, quiescence over captures and check evasions, transposition table, killer moves, MVV-LVA ordering, piece-square tables, and a fixed node budget so every game replays deterministically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
